# 通道边界方向标注

现有通道仍使用固定 A/B 坐标，正反两方向均以绿线判断上下沿，
紫色反向映射线只作盘口对照。本次改进图表表达，没有拆成两套独立统计通道。

- 上边界与冻结上界直接标注 `A多/B空`；下边界与冻结下界标注 `B多/A空`。
  图表线条选择项同步展示方向，保留原有显示选择的存储键。
- 当前绿线到达上下沿时，报价点标注 `上沿触边` 或 `下沿触边`。
  历史独立触点名称附带相同方向，位置仍使用原始统一坐标。
- 当前点悬浮分别显示两个方向距边/触边状态、各自真实毛价差、当前同轮整轮净差和筛选状态。
  触边只代表通道条件成立，不能据此认定收益达标或已经下单。
- 图下状态显示当前路线的方向；已触边时显示对应路线的整轮净差与核验状态。
  原有持仓仍显示冻结通道及目标，不把机会列表入场收益当作持仓平仓收益。
- 紫线显示控制改称“对照线”，图表说明解释统一判断坐标及方向映射。
- 窄屏悬浮压缩重复说明，保留双向毛价差、净差和筛选原因，避免内容超出图表高度。
- 边界数值、冻结目标、收益算法、触发条件、执行检查及后台进程保持原样。
  不新增接口、历史查询、交易所请求或执行等待。
